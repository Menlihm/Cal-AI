# Cal AI

Daily nutrition companion for **healthy weight loss**: calorie & macro targets, vitamin/mineral checklists, gentle eat reminders, photo check-ins, and menstrual-cycle-aware food ideas.

## Features

- **Personalized calories** via Mifflin–St Jeor BMR × activity, with safe floors (1200♀ / 1500♂)
- **Macros, fiber, water** targets for your goal pace
- **Daily vitamins & minerals** using sex- and age-aware RDA-style targets
- **Step tracker** with calorie burn estimates and step goals
- **Outdoor GPS walks** with distance, pace, and calories burned
- **Activity calculator** (walk, hike, jog, cycle, strength, yoga, and more) using MET formulas
- **Goal speed suggestions** — how many weeks to goal with diet-only vs walk/step plans
- **Eat reminders** in-app (+ optional browser notifications) when you’ve gone too long without a bite
- **Photo check-ins** with optional weight notes (stored locally)
- **Male / female** profiles; **cycle tracking** with phase-based craving suggestions grounded in common nutrition research themes
- **Mobile app (PWA)** — install to your phone home screen for a full-screen app with GPS
- Data stays **on your device** (localStorage)

## Develop

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

### Install on your phone

1. Deploy or open the app in **Chrome (Android)** or **Safari (iPhone)**.
2. Choose **Install app** / **Add to Home Screen**.
3. Allow **location** when starting an outdoor walk for GPS tracking.

## Note

Cal AI is educational self-tracking — not medical advice. Cycle food ideas synthesize common themes from micronutrient RDAs and menstrual-nutrition education; individual needs vary.
